# Data Science Internship Projects

This repository contains the projects completed during my Data Science Internship.

The projects cover different areas of Data Science, including classification, regression, clustering, and recommendation systems.

## Projects

### Month 1

#### Task 1 — Titanic Survival Classification

A machine learning classification project using the Titanic dataset.

**Main Work:**

* Data cleaning and preprocessing
* Handling missing values
* Feature engineering
* Logistic Regression
* Random Forest Classification
* Model evaluation
* Final prediction generation

**Result:**

* Random Forest Accuracy: **81.56%**
* Logistic Regression Accuracy: **80.45%**

---

#### Task 2 — Apple Stock Price Prediction

A regression project for predicting the next trading day's Apple stock closing price.

**Main Work:**

* Historical stock data preprocessing
* Feature preparation
* Linear Regression
* Model evaluation
* Actual vs Predicted price analysis

**Result:**

* MAE: **2.6353**
* RMSE: **3.7141**
* R² Score: **0.992**

---

### Month 2

#### Task 3 — Customer Segmentation

A customer segmentation project using the Customer Personality Analysis dataset.

**Main Work:**

* Data preprocessing
* Feature scaling
* K-Means clustering
* Elbow Method
* Silhouette Score
* PCA visualization

**Result:**

* Final number of clusters: **2**
* Silhouette Score: **0.34**

---

#### Task 4 — Movie Rating Prediction & Recommendation

A movie recommendation project using the MovieLens 100K dataset.

**Main Work:**

* User-movie rating matrix
* Collaborative filtering
* Truncated SVD
* Rating prediction
* Movie recommendations

**Result:**

* MAE: **0.8159**
* RMSE: **1.0282**
* Top-10 movie recommendations generated
